- **Kind:** mixed (probe / bench / engine / config)

- **Class:** engine (llama.cpp perf counters: Prompt/Generation t/s), n=4, non-anchor

## EN one-liner

Inkling-2-Mini UD-IQ3_XXS runs on V100 16GB via Unsloth llama.cpp PR #390 (sm_70): ~90/35.8 t/s pp/tg at c=2048 f16; max verified context 229376 with q4_0 KV + ub32 on real prompt+128 gen (n=4), with compute buffer/ubatch as the main ceiling.

## RU summary

Проверили запуск Inkling-2-Mini на 16GB V100. ninfer-3090 не подошёл для этого кванта (конвертер `inkling2_gguf` падает на `ffn_gate_up_exps.scale` у IQ2_XXS-слоёв UD-IQ3_XXS), mainline llama.cpp не поддерживает `inkling2` (`blk.24.attn_q.weight not found`). Рабочий путь — Unsloth llama.cpp PR #390 (`mtp-fixes`, `b1-8aa2f23`, CUDA sm_70).

Модель загружается на V100 16GB (`-ngl 999`) и генерирует. Максимальный контекст зависит не только от KV, но и от compute/pp buffer: f16 KV, ub default — до ~34816; q4_0 KV + ub64 — до ~229376 на probe `Hi -n 1`; на реальном workload (prompt+128 gen) 229376 q4_0 ub64 OOM, 229376 q4_0 ub32 прошёл n=4.

## Why this path

- **ninfer-3090:** собран sm_70, но `tools.convert --recipe inkling2_gguf` на UD-IQ3_XXS отказал: `Inkling2Error: layer 0 has unexpected tensors ['ffn_gate_up_exps.scale']`. IQ2_XXS gate_up_exps имеет per-expert F32 scale, конвертер ожидал scale только для NVFP4.
- **mainline llama.cpp:** собран sm_70, но не грузит `general.architecture=inkling2` (`check_tensor_dims: tensor 'blk.24.attn_q.weight' not found`).
- **Unsloth llama.cpp PR #390:** поддерживает Inkling2, GGUF грузится напрямую. Выбран как практичный путь для 16GB smoke/max-context.

## Caveats

- **Non-anchor**: другой движок/модель, не сравнивать напрямую с Lapilli/Basalt Qwen3.8 anchor.
- **Engine class**: это perf-счётчики llama.cpp, не client TTFT/HTTP.
- Короткий prompt и 128 gen — smoke/throughput sanity, не полноценный long-context quality/latency bench.
- `-ub 32/64/128/256` влияет на prefill/compute footprint; max-context результаты валидны для указанных настроек.
- ninfer остаётся целевым движком для Inkling2, но для UD-IQ3_XXS на этом пути есть конвертерный блокер.
