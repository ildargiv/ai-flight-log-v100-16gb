# Правила журнала

1. **Append-only.** Записи не редактируются задним числом. Ошибся в цифре — новая запись
   «Корректировка к №NNN». Старая остаётся как есть: ценность журнала в том, что видно,
   что и когда было известно.
2. **Неудача = запись того же ранга, что успех.** У каждого провала обязательны поля
   «как понять, что это оно» (признак/лог/цифра) и «что делать вместо» — иначе это жалоба,
   а не данные.
3. **Класс неудачи** — один из: `железо` / `драйвер` / `движок` / `конфиг` / `оператор`
   (моя ошибка в действиях) / `харнес` (ошибка измерения). По классу потом видно, где
   система сыпется чаще всего.
4. **Якорь.** Линия равнения одна: V100 SXM2-16GB + IQ3_S + 262K + `--kv int8` + дефолты движка
   + `STRATA_ROUTE_PRIOR=1.5`. Меряется при каждом стабильном релизе движка. Экспериментальные
   ветки (другие модели/кванты/тумблеры/движки) — отдельные записи, якорь не двигают.
   Сравнения с 32-гигабайтной картой — ссылкой на [ai-flight-log-v100](https://github.com/ildargiv/ai-flight-log-v100),
   не смешивая ряды в одной таблице.
5. **Шум.** Decode без 4 повторов на idle-сервере — не вывод, а наблюдение. Разницу <3 tok/s
   записываем как «в пределах шума». Прогон с агентским трафиком помечается `under-traffic`.
6. **Два класса цифр не смешиваются.** `engine` — тайминги движка (`strata bench run`,
   лог-строка `prompt ... = ... reused + ... read`), `client` — замеры харнеса по HTTP
   (`tools/ab_bench.py`: TTFT, общее время). У `client` prefill ниже, потому что включает TTFT
   и накладные расходы сети/очереди. В таблицах всегда указан класс.
7. **Машиночасть.** Каждая запись дублируется строкой в `journal/feed.jsonl` (поля: id, date,
   kind (успех|неудача|нейтраль|корректировка), class, hardware, engine, summary, numbers,
   links).
8. **Ссылки на сырьё:** `results/` — JSON по протоколу и сырые прогоны A/B, `logs/` — выдержки
   логов движков (обезличенные: без имени хоста, IP и путей пользователя), `configs/` — конфиги
   запуска.
9. **Публикация только после сырья.** Нет файла с прогоном — нет записи.
